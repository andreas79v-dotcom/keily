# Keily

Landingpage für die Abschlusspräsentation (Samstagsschule 2026).

- `index.html` – Seite mit Live-Stand und Zeichnungsformular
- `live.html` – Beamer-Ansicht mit großem Zähler und QR-Code
- `pdf.js` – erzeugt den Zeichnungsschein (PDF) im Browser
- Daten: Supabase-Projekt `keily-landingpage` (Tabelle `zeichnungen`, Funktionen `stand()` und `zeichnen()`)

Veröffentlichung: Cloudflare Pages, verbunden mit diesem Repo (Build-Befehl leer, Ausgabeverzeichnis `/`).
